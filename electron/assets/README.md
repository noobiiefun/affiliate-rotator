# Icon Assets

Letakkan file ikon di folder ini sebelum build:

| File       | Ukuran    | Platform |
|------------|-----------|----------|
| icon.png   | 512x512px | Linux, splash screen |
| icon.ico   | 256x256px | Windows installer & exe |
| icon.icns  | 512x512px | macOS |
| tray.png   | 32x32px   | System tray (semua platform) |

## Cara buat ikon

1. Siapkan gambar PNG 1024x1024px (logo Anda)

2. Konversi ke .ico (Windows):
   - Buka https://cloudconvert.com/png-to-ico
   - Upload PNG → pilih ukuran 256x256 → Convert → Download

3. Konversi ke .icns (macOS):
   - Buka https://cloudconvert.com/png-to-icns
   - Upload PNG → Convert → Download

4. Resize ke 512x512 untuk icon.png:
   - Bisa pakai https://www.iloveimg.com/resize-image

5. Resize ke 32x32 untuk tray.png:
   - Gunakan gambar sederhana/monokrom agar jelas di tray
